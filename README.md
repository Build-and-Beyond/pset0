# Logic101 - PSET 0: Game

Welcome to your first Logic101 problem set! In this assignment, you'll build a
simple game using Python.

## Getting Started

1. If you haven't already, run `l101 login` to authenticate with GitHub.
2. The starter code is in `game.py`.
3. Read the instructions below and implement the required functions.

## Instructions

Implement a simple grid-based game with the following features:

1. **Board Initialization**: The game should display a 5x5 grid using `---` for
   empty cells.

2. **Player Input**: Accept input in the format `A1` through `E5` (row letter,
   column number).

3. **Move Validation**: Validate that the input is within bounds and follows
   the correct format.

4. **Game Display**: After each move, redisplay the board showing the player's
   position.
